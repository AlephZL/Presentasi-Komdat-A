Fondasi Utama

5 Komponen Komunikasi Data

Struktur pembentuk jalur transfer informasi dari sumber hingga tujuan.

1. Sumber Data

Data Source

Titik awal penghasil informasi mentah (komputer, sensor, kamera, input user).

Contoh: PC, Kamera CCTV

2. Pengirim

Transmitter

Mengubah & mengkodekan sinyal digital/analog serta memperkuat transmisi (modulasi).

Contoh: Modem, NIC, Router

3. Media Transmisi

Transmission Medium

Jalur fisik/nirkabel perantara gelombang (Twisted pair, Fiber Optic, Radio RF)[cite: 1].

Contoh: Kabel UTP, Wi-Fi 5GHz

4. Penerima

Receiver

Menangkap sinyal, melakukan decoding sinyal kembali ke format data, & verifikasi eror[cite: 1].

Contoh: Network Interface, Antenna

5. Tujuan

Destination

Titik akhir tempat data diproses, dianalisis, disimpan, atau ditampilkan ke user[cite: 1].

Contoh: Database Server, Monitor

Teori & Standarisasi

Klasifikasi & Karakteristik Komunikasi

Berdasarkan Arah Komunikasi[cite: 1]

1. Simplex (Satu Arah)[cite: 1] TV, Radio[cite: 1]

Penerima pasif tanpa kanal umpan balik sama sekali[cite: 1].

2. Half-Duplex (Dua Arah Bergantian)[cite: 1] Walkie-Talkie[cite: 1]

Bisa mengirim & menerima, tetapi bergantian (tidak simultan)[cite: 1].

3. Full-Duplex (Dua Arah Bersamaan)[cite: 1] Telepon, Video Call[cite: 1]

Kedua pihak dapat berbicara dan mendengar secara serentak[cite: 1].

4 Karakteristik Kunci Data Komunikasi[cite: 1]

1. Pengiriman[cite: 1]

Data harus sampai ke tujuan yang tepat dan eksklusif[cite: 1].

2. Akurasi[cite: 1]

Data tidak boleh terdistorsi atau korup saat diterima[cite: 1].

3. Ketepatan Waktu[cite: 1]

Data real-time (audio/video) tak boleh mengalami latensi tinggi[cite: 1].

4. Jitter[cite: 1]

Variasi jeda kedatangan antar-paket data di sisi penerima[cite: 1].

Mode Transmisi Tambahan: Serial (1 bit berurutan, USB) vs Paralel (multi-bit simultan, Bus CPU)[cite: 1].
